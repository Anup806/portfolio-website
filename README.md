# Portfolio Website

Simple single-page portfolio for Anup Rai built with HTML, CSS, and JavaScript.

## Folder Structure

```text
Portfolio Website/
├─ index.html
├─ styles.css
├─ script.js
└─ README.md
```

## Run Locally

1. Open the `Portfolio Website` folder in VS Code.
2. Open `index.html` in a browser, or use a local server such as Live Server.
3. If you have Python installed, you can also run a simple server from this folder:

```bash
python -m http.server 8000
```

4. Visit `http://localhost:8000`.
